# Alert App

Users set up alerts (news categories and keywords) and get notified by email or Slack. There is also an admin view.
The full plan and all decisions are in [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md). Read it before starting new work.

## Repository

- Monorepo with npm workspaces: `alert-app-frontend/`, `alert-app-backend/`, `packages/shared/`.
- Run `npm install` from the repo root only. There is one `package-lock.json` at the root.
- `packages/shared` is consumed as built code (`dist/`). After changing it, run `npm run build -w @alert-app/shared` or keep `npm run dev:shared` running.
- Local services: `npm run db:up` (Postgres on host port **5433**, Redis on 6379).

## Working style

- The developer is a frontend developer who is new to backend work. Explain backend concepts when introducing them.
- Work step by step and stop after each step so it can be checked. Do not commit unless asked.
- **The frontend folder structure is not final.** Before creating new folders or moving files, discuss the structure
  with the developer (see "Open questions" in docs/PROJECT_PLAN.md).

## Rules

- **Dates: always use `date-fns`** (and `@date-fns/tz` for time zones) for parsing, formatting and date calculations.
  Never format dates manually or with `toLocaleString`, `toLocaleDateString` or `toLocaleTimeString`.
  Do not add moment, dayjs or luxon.
- **Styling:** the MUI theme is the single source of truth for colors, typography and spacing.
  Use SASS modules (`*.module.scss`) for layout and custom styling, and reuse theme values through MUI CSS variables (`var(--mui-...)`).
  Do not override MUI internals with global SASS. No Tailwind.
- **i18n:** all user-facing text goes through i18next (`t()`). No hard-coded UI strings.
- **Server state** uses TanStack Query. Do not add Redux or Zustand.
- **Forms** use React Hook Form + Zod. Put shared schemas in `packages/shared`.
- **Extensibility:** news sources implement `NewsSourceAdapter`, and notification channels implement `NotificationChannel`.
  Categories are our own `AppCategory` list, mapped per provider.
- **Backend uses ES modules:** local imports end in `.js` (`import { X } from './x.js'`).
  Never edit `alert-app-backend/src/generated/` (Prisma client, regenerated by `prisma generate`).
- Formatting: Prettier (root `.prettierrc`). Run `npm run format` before finishing a change.
